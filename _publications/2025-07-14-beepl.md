BeePL is a domain-specific language for eBPF, the Linux mechanism for running small programs inside the kernel.
Its type system checks safety properties such as memory safety, termination, and correct use of helper functions in the source program.
Where a property can't be checked statically, such as dynamic bounds, the compiler inserts runtime checks that preserve the program's meaning.
BeePL compiles through CompCert, a verified C compiler, which the project extends with an eBPF backend.

I worked on this as a proof engineer in the Virginia Tech Systems Software Research Group, on the type system and compiler verification in Rocq.
